## How to View Your Collaborations on GitHub

To view repositories where you are a collaborator on GitHub, follow these steps:

### Method 1: Using the GitHub Website

1. **Log in** to your GitHub account at [github.com](https://github.com)
2. Go to **Settings** (click your profile picture in the top-right corner, then select "Settings")
3. In the left sidebar, click on **Repositories**
4. This page shows all repositories you have access to, including those where you are a collaborator

### Method 2: Using the Search Feature

1. Go to [github.com](https://github.com)
2. In the search bar, type: `user:YOUR_USERNAME is:collaborator`
3. Replace `YOUR_USERNAME` with your actual GitHub username
4. Press Enter to see repositories where you are a collaborator

### Method 3: Direct URL

Visit the following URL (replace `YOUR_USERNAME` with your username):
```
https://github.com/YOUR_USERNAME?tab=repositories
```

### Method 4: Using GitHub API

You can also use the GitHub API to list repositories:
```
GET /user/repos?affiliation=collaborator
```
